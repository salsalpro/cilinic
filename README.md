# Mahzar Clinic — React Demo

نمونه‌ی فرانت‌اند برای «کلینیک پوست، مو و زیبایی ماه زر» با تمرکز روی ارائه‌ی اولیه به مشتری.

## اجرا

```bash
npm install
npm run dev
```

برای build نهایی:

```bash
npm run build
npm run preview
```

## ویژگی‌ها

- React + Vite
- کاملاً RTL و فارسی
- Responsive برای موبایل / تبلت / دسکتاپ
- بدون بک‌اند
- فرم رزرو نمایشی
- FAQ تعاملی
- Google Maps embed و لینک مسیریابی
- استفاده از تصاویر واقعی ارسال‌شده از کلینیک
- طراحی اختصاصی با الهام از هویت بصری مشکی / طلایی / سفید / صورتی ملایم

> توجه: این پروژه Demo Concept است. اطلاعات پزشکی، ساعت کاری، تیم پزشکان و محتوای نهایی باید قبل از انتشار عمومی توسط کلینیک تأیید شوند.
